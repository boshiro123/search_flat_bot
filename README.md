## Telegram бот для мониторинга объявлений о аренде квартир (Минск)

Бот парсит 3 сайта каждые 60 секунд и присылает новые объявления:

- [Kufar](https://re.kufar.by/l/minsk/snyat/kvartiru?cur=USD&prc=r%3A0%2C350)
- [Domovita](https://domovita.by/minsk/flats/rent?rooms=1%2C2&price%5Bmin%5D=&price%5Bmax%5D=350&price_type=all_usd)
- [Realt.by](https://realt.by/rent/flat-for-long/?addressV2=%5B%7B%22townUuid%22%3A%224cb07174-7b00-11eb-8943-0cc47adabd66%22%7D%5D&page=1&priceTo=350&priceType=840&rooms=1&rooms=2)

## ✨ Новые возможности

### 🎯 Индивидуальные фильтры

Каждый пользователь может настроить свою персональную максимальную цену в USD

### 📢 Работа в каналах

Бот может работать не только в личных чатах, но и публиковать объявления в Telegram-каналах!

### 💾 PostgreSQL

Все данные теперь хранятся в базе данных PostgreSQL, что обеспечивает:

- Надежное хранение пользовательских настроек
- Отслеживание просмотренных объявлений для каждого пользователя отдельно
- Возможность масштабирования на большое количество пользователей

## 🚀 Быстрый старт

### Вариант 1: Запуск через Docker (рекомендуется)

1. **Создайте файл `.env`** с переменными окружения:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

2. **Запустите через docker-compose:**

```bash
docker compose up -d --build
```

3. **Просмотр логов:**

```bash
docker compose logs -f search-flat-bot
```

4. **Остановка:**

```bash
docker compose down
```

### Вариант 2: Локальный запуск

1. **Установите зависимости:**

```bash
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate  # Windows

pip install -r requirements.txt
playwright install chromium
```

2. **Настройте PostgreSQL:**

```bash
# Установите PostgreSQL (если еще не установлен)
# Создайте базу данных:
createdb search_flat_bot

# Создайте пользователя:
psql -c "CREATE USER bot_user WITH PASSWORD 'bot_password';"
psql -c "GRANT ALL PRIVILEGES ON DATABASE search_flat_bot TO bot_user;"
```

3. **Создайте файл `.env`:**

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
DATABASE_URL=postgresql://bot_user:bot_password@localhost:5432/search_flat_bot
```

4. **Запустите бота:**

```bash
python -m src.main
```

## 📱 Использование бота

### Для личных чатов

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Настройте фильтры командой `/filter`
4. Получайте уведомления о новых объявлениях!

### 🎪 Для каналов

#### Шаг 1: Создайте канал

1. Откройте Telegram
2. Создайте новый канал: **Меню → Новый канал**
3. Выберите **Публичный** или **Приватный** канал
4. Настройте название и описание

#### Шаг 2: Добавьте бота как администратора

1. Откройте настройки канала
2. Перейдите в **Администраторы**
3. Нажмите **Добавить администратора**
4. Найдите вашего бота
5. Выдайте права:
   - ✅ **Публикация сообщений** (обязательно!)
   - Остальные права можно отключить

#### Шаг 3: Активируйте бота в канале

1. В канале отправьте команду `/start` (от имени администратора)
2. Бот подтвердит подключение сообщением
3. Готово! Теперь все новые объявления будут публиковаться в канале

#### Настройка максимальной цены для канала

Администратор канала может настроить максимальную цену:

1. Напишите боту в **личные сообщения**
2. Используйте команду `/filter`
3. Установите максимальную цену
4. Этот фильтр будет применяться к объявлениям в канале

**Примечание:** Каждый канал/пользователь имеет свои индивидуальные настройки!

## 🤖 Команды бота

### Основные команды

- `/start` — подписка на уведомления (для личного чата или канала)
- `/stop` — отписка от уведомлений
- `/help` — справка по командам

### Настройка фильтра

- `/filter` — настроить максимальную цену
- `/myfilter` — посмотреть текущие настройки

### Просмотр объявлений

- `/kufar` — показать последнее объявление с Kufar
- `/domovita` — показать последнее объявление с Domovita
- `/realt` — показать последнее объявление с Realt.by

### Другое

- `/cancel` — отмена текущей операции

## 🔧 Продвинутая настройка

### 🔍 Как получить chat_id канала

Если вы хотите добавить канал в whitelist (`ALLOWED_CHAT_IDS`), вам нужно узнать его chat_id. Есть несколько способов:

#### Способ 1: Использовать готовый скрипт `get_chat_id.py`

1. **Запустите скрипт:**

   ```bash
   python get_chat_id.py
   ```

2. **В канале:**

   - Добавьте бота как администратора канала (нужны права на чтение сообщений)
   - Отправьте любое сообщение в канал

3. **Получите результат:**

   ```
   Chat ID: -1001234567890
   Type: channel
   Title: Мой канал
   ```

4. **Скопируйте chat_id** и добавьте в `.env`:
   ```env
   ALLOWED_CHAT_IDS=-1001234567890
   ```

#### Способ 2: Через бота вручную

1. Добавьте бота в канал как администратора
2. Запустите бота (должен работать)
3. Отправьте `/start` в канале
4. Проверьте логи бота:
   ```bash
   docker compose logs search-flat-bot | grep "chat_id"
   ```

#### Способ 3: Использовать @userinfobot

1. Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
2. Он покажет информацию о канале, включая ID

**💡 Важно:**

- Chat ID канала **всегда начинается с `-100`** (например: `-1001234567890`)
- Для личного чата это обычное число (например: `733743450`)

### 🔒 Ограничение: только один активный канал

Бот может работать только с **одним активным каналом** одновременно:

- ✅ Можно подключить несколько личных чатов (для администраторов)
- ✅ Можно подключить **один** канал или группу
- ❌ Нельзя подключить второй канал, пока первый активен

**Как это работает:**

1. **Первый канал подключается** через `/start` → бот начинает работать
2. **Попытка подключить второй канал** → бот отклоняет:
   ```
   ❌ Бот уже используется другим каналом!
   Активный канал: Мой канал
   Для подключения этого канала, сначала остановите бот в другом канале командой /stop
   ```
3. **Отключаете первый канал** через `/stop` → теперь можно подключить другой

**Для администраторов (личные чаты):**

- Можно иметь несколько активных администраторов одновременно
- Ограничение действует только на каналы/группы

После запуска `docker compose up -d` вы можете открыть pgAdmin для управления базой данных:

1. **Откройте браузер:** [http://localhost:5050](http://localhost:5050)

2. **Войдите с учетными данными:**

   - Email: `admin@admin.com`
   - Password: `admin`

3. **Подключитесь к базе данных:**
   - Нажмите "Add New Server"
   - **General → Name:** `Search Flat Bot`
   - **Connection:**
     - Host: `postgres`
     - Port: `5432`
     - Maintenance database: `search_flat_bot`
     - Username: `bot_user`
     - Password: `bot_password`
   - Нажмите "Save"

Теперь вы можете просматривать таблицы, выполнять SQL-запросы и управлять данными!

## 📊 Архитектура

### Технологии

- **Python 3.11+**
- **python-telegram-bot** — работа с Telegram Bot API
- **PostgreSQL** — хранение данных
- **SQLAlchemy** — ORM для работы с БД
- **BeautifulSoup4 + lxml** — парсинг HTML
- **Playwright** — рендеринг JavaScript (fallback)
- **Docker + Docker Compose** — контейнеризация

### Структура базы данных

- **users** — пользователи и каналы
- **user_filters** — индивидуальные фильтры каждого пользователя
- **seen_listings** — просмотренные объявления (отдельно для каждого пользователя)
- **last_dates** — даты последних постов по источникам
- **global_state** — глобальное состояние бота

### Как это работает

1. Каждые 60 секунд бот парсит все три сайта
2. Определяет, какие объявления новые для каждого пользователя/канала
3. Применяет индивидуальные фильтры каждого пользователя
4. Отправляет только релевантные объявления каждому подписчику

## 🐛 Troubleshooting

### Бот не отвечает в канале

- Убедитесь, что бот добавлен как **администратор** канала
- Проверьте, что у бота есть права на **публикацию сообщений**
- Отправьте `/start` в канале (важно: команда должна быть отправлена **в самом канале**, а не в настройках)
- Если бот все равно не отвечает, попробуйте:
  1. Удалить бота из администраторов
  2. Добавить его снова с правами публикации
  3. Отправить `/start` еще раз

### Не приходят уведомления

- Проверьте, что вы подписаны: `/start`
- Проверьте вашу максимальную цену: `/myfilter`
- Возможно, новых объявлений в вашем ценовом диапазоне просто нет

### Ошибки подключения к БД

```bash
# Проверьте логи
docker compose logs postgres

# Перезапустите контейнеры
docker compose restart
```

### Playwright не работает

```bash
# Переустановите браузеры
playwright install chromium --with-deps
```

## 📝 Примечания

- **Первый запуск:** Бот прогревает кэш — текущие объявления отмечаются как «уже виденные», чтобы не заспамить чат
- **Персистентность:** Все данные хранятся в PostgreSQL, при перезапуске бота ничего не теряется
- **Масштабируемость:** Бот может обслуживать неограниченное количество пользователей и каналов
- **Индивидуальные фильтры:** Каждый пользователь и канал имеет свои настройки цены
